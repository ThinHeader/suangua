# 算卦

一个基于 React + TypeScript + Vite 的在线起卦小工具，部署在 [gua.dongpouu.top](https://gua.dongpouu.top/)。

用户选择起卦方式后，前端完成卦象计算与结果展示，纯静态站点，无需后端。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 技术栈

- React + TypeScript
- Vite
- Oxlint
